# ☕ Java — rebuilding the basics

**Current status:** Relearning from the beginning.

## Study order
1. Install a JDK and choose an editor.
2. Print output, understand variables and types.
3. Practice user input and conditionals.
4. Practice `for` and `while` loops.
5. Write methods; understand parameters and return values.
6. Understand arrays, strings, and simple classes.
7. Move to DSA exercises.

## Starter exercises
- Print a greeting.
- Calculate the total of two numbers.
- Check if a number is even or odd.
- Print numbers from 1 to 20.
- Find the largest number in an array.

For each exercise: write the code yourself, run it, describe how it works, then try an edge case.

**Not yet completed:** These are planned activities, not finished projects.
