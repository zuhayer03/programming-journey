# 🧠 Data Structures and Algorithms

A place for class concepts and solutions explained in plain language.

## Sequence
1. Big O: time and space complexity
2. Arrays and strings
3. Linear and binary search
4. Sorting
5. Linked lists, stacks, and queues
6. Hash maps and sets
7. Recursion
8. Trees and graphs

## Problem template
**Problem:** What am I asked to do?

**Example:** Write a small input/output example.

**Approach:** Explain the algorithm in your own words.

**Complexity:** Explain time and space usage.

**Testing:** Try empty input, one item, duplicates, and large inputs where relevant.

**Reflection:** What was confusing? What did I learn?

Start with array scanning and linear search, then progress.
