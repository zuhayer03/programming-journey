# AlgoArena — Algorithm Racing Simulator

A Java console application that compares Bubble Sort, Selection Sort, and Insertion Sort on the **same seeded random input**. It verifies output against `Arrays.sort` and reports average execution times for multiple input sizes.

## Run

```bash
javac AlgoArena.java AlgoArenaTest.java
java AlgoArena
java AlgoArena 10
java AlgoArenaTest
```

Requires a JDK. No external dependencies. Results are educational microbenchmarks, not scientific performance measurements or a graphical simulator. Future enhancement: add charts and other algorithms.
