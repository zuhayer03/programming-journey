Threat model

The calculator rejects arbitrary Python syntax, function calls and attribute access. ToolPilot does not expose shell commands or network access. This reduces—but does not eliminate—implementation risks.

System boundaries

The website's Mission Control demo runs in the browser and does not communicate with the Python implementation. The demo is not real-time production telemetry.

Next engineering milestone

Introduce optional LLM planning behind a validated schema, add explicit human approval gates, and test the browser and Python tool implementations for consistency.
