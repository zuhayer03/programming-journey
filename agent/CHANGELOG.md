# ToolPilot Changelog

## 0.1.0 — Experimental prototype
- Deterministic routing with explicit command prefixes.
- Bounded AST-based arithmetic evaluator; no `eval` or shell execution.
- Text statistics and explicit TODO/TASK extraction.
- Structured execution trace, CLI, and unit tests.
- Browser-based simulation in `docs/lab.html` (not connected to Python).

**Next milestones:** optional model-based planner, human approval gates, tool schemas, integration tests, structured tracing and benchmarks measured from actual runs.
