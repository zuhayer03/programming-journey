### 02 / Beyond the illustrations

[**Interactive Lab ↗**](https://zuhayer03.github.io/programming-journey/lab.html) lets you explore separate browser demos for sorting, sample TCP checks, synthetic login events and fictional budgets. Those JavaScript experiments are not the same code as the original Java/Python programs.

[**Animated 29-tool dashboard ↗**](https://zuhayer03.github.io/programming-journey/dashboard.html) brings original product logos and smooth motion into a searchable visual directory.

### 03 / About the animation system

The source is in [**render_project_demos.py**](https://github.com/zuhayer03/zuhayer03/blob/main/scripts/render_project_demos.py), and the outputs are published automatically through the profile repository's GitHub Actions workflow. Each GIF has a high-resolution PNG alternative for reduced-motion preferences.
